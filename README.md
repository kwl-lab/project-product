# ESP32 智能小车复刻 — 1个月双人项目路线

> 团队：2 名大三学生（会 C/C++ 与 Python，无硬件经验）｜预算：≤300 元｜周期：1 个月
> 目标：复刻资料最全的经典硬件项目「智能小车」，走完 硬件选型 → 电路连接 → 嵌入式编程 → 整车集成 → 无线控制 → 文档沉淀 的完整闭环。

## 为什么是智能小车（备选项目池）

| 项目 | 难度 | 成本 | 特点 |
|---|---|---|---|
| **智能小车（本项目）** | ★★ | 200-300元 | 教程最多、覆盖全链路、易分工、可扩展图传 |
| 桌面小电视/天气时钟 | ★★ | 150-250元 | 软件重硬件轻，适合下一个项目 |
| 客制化机械键盘 | ★★★ | 300-600元 | 需画 PCB，成品可售卖 |
| 机械臂 | ★★★★ | 400-800元 | 逆运动学数学重 |
| 四轴无人机 | ★★★★★ | 800+元 | 调试难、有一定危险性 |

## 一、复刻目标（产品定义）

- **必做（基础版）**：4WD 小车，超声波避障 + 红外寻迹，电池供电独立运行
- **选做（时间够）**：ESP32 开 WiFi 热点 + Web 服务器，手机浏览器摇杆遥控
- **母本工程**：先找 1-2 个完整开源工程/视频系列当参照，照着接线和代码跑通，再改成自己的。来源：立创开源广场 oshwhub.com 搜「ESP32 小车」、GitHub 搜 `esp32 car`、B站搜「ESP32 智能小车」
- **交付物**：能跑的小车 + 本仓库（代码/接线图/材料表/照片/复盘）

## 二、需要学什么（按优先级）

1. **电路基础速成**（等快递的 3-5 天学完）：电压/电流/电阻、欧姆定律、共地概念、面包板、万用表读数、PWM、H 桥原理（了解即可，不要求推导）
2. **嵌入式 C**（复用现有 C++ 基础，成本极低）：GPIO 输入输出、PWM 输出、串口 UART、I2C、延时
3. **ESP32 Arduino 框架**：板卡安装、烧录、WiFi AP 模式 + WebServer 库
4. **结构与供电**：底盘组装、电池方案、稳压

> ⚠️ 安全须知：18650 电池勿短路、勿反接；烙铁注意防烫。

## 三、零件清单（合计约 200-260 元）

| 零件 | 数量 | 预算 | 淘宝关键词 |
|---|---|---|---|
| ESP32-WROOM-32 开发板 | 1 | 25-35元 | `ESP32 开发板` |
| 4WD 底盘套件（亚克力 + TT马达×4 + 轮子） | 1 | 30-50元 | `智能小车底盘 4WD` |
| L298N 电机驱动模块（4 电机需 2 个；TB6612 更好但教程少） | 2 | 10-16元 | `L298N 电机驱动模块` |
| HC-SR04 超声波测距 | 1 | 4元 | `HC-SR04` |
| TCRT5000 红外寻迹模块 | 3-5 | 10元 | `TCRT5000 寻迹模块` |
| 18650 电池盒（2节）+ 电池 | 1 | 30-40元 | `18650 电池盒 2节` |
| 杜邦线（公母各1排）+ 面包板 | — | 18元 | `杜邦线` `面包板` |
| 螺丝刀/扎带/双面胶 | — | 15元 | — |
| 备用金（烧件替换） | — | 30元 | — |

- **供电方案（新手第一大坑）**：电池盒 → L298N 供电机；ESP32 用旧充电宝 USB 供电；**两者必须共地**
- **懒人替代**：淘宝直接买「Arduino/ESP32 智能小车套件」（¥120-250，含全套零件+教程），省去零散采购和选型

## 四、软件安装清单

- **Arduino IDE 2.x**（arduino.cc 下载）— 必装
- **ESP32 板卡包**：文件 → 首选项 → 附加开发板管理器网址填 `https://espressif.github.io/arduino-esp32/package_esp32_index.json` → 工具 → 开发板管理器安装 esp32
- **CH340/CP2102 USB 驱动**（烧录失败先查这个；很多数据线只能充电不能传数据）
- **git**（已有）— 代码和文档提交到本仓库
- 可选：PlatformIO（VS Code 插件，习惯后可换）、Fusion 360 教育版（外壳）、立创EDA（进阶画 PCB）
- 遥控无需装 App：手机浏览器直接打开 ESP32 的网页即可

## 六、四周执行计划（里程碑式拆分）

### 阶段 0（第 1 天）
淘宝下单全部零件；等快递期间装好软件、学完电路基础、选定母本教程。

### 阶段 1（第 1 周末）
点亮第一个 LED → PWM 呼吸灯 → 串口打印。
**验收**：三个例程全部跑通，串口监视器有输出。

### 阶段 2（第 2 周）
两条线并行，桌面测试（不上车）：

| 人A | 人B |
|---|---|
| L298N 驱动电机正反转 + PWM 调速 | HC-SR04 测距 + 寻迹模块读值 |

**验收**：电机随程序正反转、可调速；串口实时打印距离/寻迹值。

### 阶段 3（第 3 周）
整车集成 — 组装底盘、接线、共地检查；避障逻辑（前方 <20cm 停 → 转向 → 继续）；寻迹走黑线。
**验收**：避障模式跑 3 分钟不撞墙；寻迹跑通一小段赛道。

### 阶段 4（第 4 周）
WiFi 遥控（选做）+ 收尾 — ESP32 开热点跑 WebServer，浏览器摇杆控制；整理走线；更新 README（接线图 + 材料表 + 照片 + 复盘）。
**验收**：手机遥控顺畅；仓库文档完整。

## 七、两人分工

- **人A（功率/机电线）**：电机驱动、供电、底盘组装
- **人B（感知/软件线）**：传感器、WiFi/Web、代码架构
- 规则：每阶段各自独立验收后再合流联调；共用本仓库，每天提交

## 八、排障顺序（卡住时按此排查）

接线（共地/正负极）→ 供电电压（万用表量）→ 代码逻辑（串口打印定位）→ 硬件损坏（换件）

- 烧不进程序：换数据线 → 装 CH340 驱动 → 按住 BOOT 再烧
- 电机不转：万用表量 L298N 输出电压；检查共地
- 一个月做不完：砍 WiFi 遥控，基础版（避障 + 寻迹）即为完整交付
